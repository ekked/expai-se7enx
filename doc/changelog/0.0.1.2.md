# expai 0.0.1.2

## Updated

- Updated: Every translation file of expai validates again. The messages for parallel runs and checkpoints had been
  inserted inside the still open context before them, so the files no longer validated against the kernel's
  translation schema (`schemas/translation/ts.rng`), and the kernel skips a file that does not validate. In 0.0.1.0
  and 0.0.1.1 every expai message was therefore shown untranslated, in German too, and each one wrote a "Missing
  translation" debug line, among them `extension/expai/audit` "Exponential Intelligence" on every admin page.
  The files are fixed in eng-US, ger-DE and untranslated. A new test,
  `tests/phpunit/unit/core/expAiTranslationFilesTest.php`, validates every translation file against the
  installation's schema and checks that no context is nested in another.
