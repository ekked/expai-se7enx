# expai 0.0.1.6

## Fixed

- Fixed: expai installs on PHP 8.0 again. Version 0.0.1.5 required PHP 8.1 in composer.json, although its code runs on
  PHP 8.0 (checked: every file compiles, the probe, the script tests and real calls to two providers run on 8.0), so
  an installation on PHP 8.0, which Exponential supports, could not install it. The requirement is `>=8.0` again.
- Fixed: The usage chart of the dashboard has no focusable bar inside its picture hidden from screen readers (the
  table beside it carries the numbers), and the links of a turn of the log follow its summary instead of sitting
  inside it.
