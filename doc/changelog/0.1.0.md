# expai 0.1.0

The first release of Exponential Intelligence (Powered by Claude from Anthropic).

- Added: The Intelligence tab on the content full view (content and media sections): a conversation with Claude per
  user and node, with lookups and draft writing through tools, run as the logged-in editor.
- Added: The conversation history: one collapsible row per exchange (only the latest open), Expand all / Collapse
  all, Show older, kept on the server per user and node.
- Added: A bounded context window: older exchanges become a short summary, the last ones are sent word for word
  (`[AssistantSettings] ContextWindowTurns`).
- Added: The tools get_node, list_children, get_tree_context, list_creatable_classes, get_class_definition,
  create_draft and update_draft, registered in expai.ini.
- Added: "Save as drafts" and "Send for approval" (the regular publish operation as the editor), with a per-draft
  hint whether an approval workflow applies; Discard.
- Added: The content edit form integration through content.ini AdditionalTemplates[]: "Fill the fields" from a brief
  and the field actions Write, Rewrite, Shorten, Translate and Suggest, filling Tiptap, the Online Editor or plain
  fields for review.
- Added: The "Exponential Intelligence" label on versions written by expai: in My drafts, the drafts page, version
  views, edit forms and approval items.
- Added: The dashboard page expai/dashboard in the Dashboard tab's left menu: period and Mine / Site switches,
  status badges, cost, tokens, requests and drafts with trends, a chart per day, limits and API rate limits, top users,
  Start writing at a preselected location, recent drafts with icon links; the dashboard block and the log page
  expai/log (requests as turns, filters, totals per day and user, CSV); all choices are view parameters.
- Added: Usage tracking in expai_usage_log (one row per request: tokens, latency, tools, errors, rate limit headers;
  user ids only), a retention cronjob part, optional limits per conversation, session, user and day or month and site
  month, and an estimated cost from a price table (expAiCost, with a unit test of the model matcher).
- Added: The model choice: AllowedModels[] with labels, the preference expai_model, the policy expai/settings.
- Added: The policies expai/write, expai/log and expai/settings; the ezjscore functions expai::load, history, chat, reset, drafts,
  keep, send, discard, field, fill, model and labels.
- Added: The tables expai_draft_log, expai_conversation and expai_usage_log for MySQL, PostgreSQL, SQLite, Oracle and MongoDB, and
  bin/php/expaischema.php to install them.
- Added: Extension points for tools, field actions, panel and edit form sections, providers and JavaScript hooks, with
  the example extension doc/examples/expaiexample.
- Added: Translations eng-US and ger-DE, and the untranslated template.
