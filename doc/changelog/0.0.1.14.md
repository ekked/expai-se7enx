# expai 0.0.1.14

The extension's documentation moves into the help center of the administration, where the kernel has one. Works with
Exponential 6.0.14 and later:

- **Exponential 6.0.15 and later**: the documentation is read in the help center, which shows the documentation of
  every active extension (the folder and category "Extensions", `exphelp/extensions`).
- **Exponential 6.0.14**, which has no help center: EI: Help, the dashboard's Help link and the "?" links open the
  same page on GitHub, in the tree of this release
  (`https://github.com/se7enxweb/expai/blob/v0.0.1.14/doc/<page>.md`). Nothing needs the help center: no class,
  template or policy of it is required, and the menu entry is not hidden.

## Added

- Added: `settings/exphelp.ini.append.php`: the Help control of the top bar opens the page of the expai view the user
  is on (the dashboard, Vector, chains, the missing alt text report, EI: Summary, the log, budgets, models).
- Added: User manual pages in `doc/manual/`: one question per page, with who may do it, the steps, what can go wrong
  and the related pages.
- Added: `expAiHelpLinks` (classes/expaihelplinks.php): the addresses of the documentation, and the page names of the
  old view mapped to them. `helpCenter()` decides where a page is read: in the help center when the running kernel has
  one that shows extension documentation (`expHelpDocumentIndex::extensions()`, the module `exphelp`, exphelp.ini
  `[IndexSettings] ActiveExtensionDocs` not disabled) and the user holds `exphelp/read`; otherwise on GitHub, pinned
  to the release's tag. A page name the extension does not have leads to the index. Test:
  `tests/phpunit/unit/core/expAiHelpLinksTest.php`.

## Updated

- Updated: The documentation is read in the help center with the same viewer, contents and search as the rest of the
  help, instead of the extension's own help pages. Every link goes through `expai/help`, which redirects: Dashboard >
  EI: Help and the dashboard's Help link to the extension's index (`exphelp/extensions/expai`), each "?" link
  (`expai/help/(page)/<page>`) to its page (`exphelp/viewer/ext/expai/<page>.md`); on Exponential 6.0.14, or for a
  user without `exphelp/read`, to the same page on GitHub. The menu entry keeps the view's own policy (`expai/write`
  or `expai/summary`, asked by `[MenuAccessSettings] CheckViewAccess`), so it shows with or without the help center.
- Updated: The links to the documentation of Exponential point to `doc/en/us/`, where it moved so it can be translated
  (the JSON package format, the audit, the RAD extension surface, the ezjscore services).

## Removed

- Removed: The extension's own Markdown renderer and help page (`expAiHelp`, classes/expaihelp.php,
  `design:expai/help.tpl`, its styles in expai.css and `tests/expaihelp_test.php`); the help center renders the pages.
