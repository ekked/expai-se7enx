# expai 0.0.1.14

The extension's documentation moves into the help center of the administration. Needs the help center of
Exponential 6.0.15, which shows the documentation of every active extension (the folder and category "Extensions",
`exphelp/extensions`); with an older Exponential, EI: Help and the "?" links lead to a page it does not have.

## Added

- Added: `settings/exphelp.ini.append.php`: the Help control of the top bar opens the page of the expai view the user
  is on (the dashboard, Vector, chains, the missing alt text report, EI: Summary, the log, budgets, models).
- Added: User manual pages in `doc/manual/`: one question per page, with who may do it, the steps, what can go wrong
  and the related pages.
- Added: `expAiHelpLinks` (classes/expaihelplinks.php): the addresses of the documentation in the help center, and the
  page names of the old view mapped to them. Test: `tests/phpunit/unit/core/expAiHelpLinksTest.php`.

## Updated

- Updated: The documentation is read in the help center with the same viewer, contents and search as the rest of the
  help, instead of the extension's own help pages. Dashboard > EI: Help and the dashboard's Help link open the
  extension's index there (`exphelp/extensions/expai`); each "?" link opens its page
  (`exphelp/viewer/ext/expai/<page>.md`). The old addresses redirect: `expai/help` to the index,
  `expai/help/(page)/<name>` to the same page. The menu entry needs `exphelp/read`, the policy of the help center.
- Updated: The links to the documentation of Exponential point to `doc/en/us/`, where it moved so it can be translated
  (the JSON package format, the audit, the RAD extension surface, the ezjscore services).

## Removed

- Removed: The extension's own Markdown renderer and help page (`expAiHelp`, classes/expaihelp.php,
  `design:expai/help.tpl`, its styles in expai.css and `tests/expaihelp_test.php`); the help center renders the pages.
