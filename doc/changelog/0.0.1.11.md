# expai 0.0.1.11

No class or setting changes; templates and stylesheets of the admin only.

## Updated

- Updated: The usage bars, the daily chart of the dashboard and the response time sparkline of the model card take
  their width or height from the shared `a4-pct-<n>` class of the admin component stylesheet instead of a `style=""`
  attribute, which a Content-Security-Policy without `'unsafe-inline'` drops. The admin templates carry no inline
  CSS any more; `tests/expaiadmininlinecsstest.php` (no database) keeps it that way.
- Updated: In dark mode the current choice of the period, scope and chart switches is readable (4.5:1 or more), and
  the "Start it under Models" link is at least 24px high (WCAG 2.2 target size).
