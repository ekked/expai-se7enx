# expai 0.0.1.17 (2026-10-21)

The old help reader is removed. expai now needs the help center of Exponential 6.0.15 for its documentation.

## Removed

- Removed: The view `expai/help` (and `expai/help/(page)/<name>`), which redirected old bookmarks and every help link
  on a kernel without the help center. It now answers with the kernel's "not found".
- Removed: The GitHub fallback (`expAiHelpLinks::githubUrl()` and the constants `GITHUB_REF` and `GITHUB_BASE`); the
  documentation is no longer opened on GitHub.
- Removed: The menu fallback for Exponential 6.0.14 (`expAiHelpLinks::menuFallback()` and its `request/input`
  listener in settings/site.ini.append.php), and `helpCenter()`, `setHelpCenter()`, `kernelHasHelpCenter()` and
  `target()`, which chose between the help center and `expai/help`.

## Updated

- Updated: EI: Help, the dashboard's Help link and the "?" links always open the help center
  (`exphelp/extensions/expai`, `exphelp/viewer/ext/expai/<page>.md`). A user without `exphelp/read` gets the help
  center's access denied instead of a page on GitHub.
- Updated: The tests drop the fallback cases and check that the old reader is gone; the help-center cases stay.

## Upgrade notes

- The help center is that of Exponential 6.0.15. On an older kernel (6.0.14) EI: Help, the dashboard's Help link and
  the "?" links open nothing useful; read the files in the extension's `doc/` folder there. Everything else in expai
  still runs on 6.0.14, so composer.json keeps `se7enxweb/exponential: ^6.0.14` until 6.0.15 is published.
- Bookmarks to `expai/help` no longer work; use Dashboard > EI: Help.
