# expai 0.0.1.1

## Updated

- Updated: The "Decorative (empty alt text)" button of the alt text feature is disabled for an image field whose
  class attribute has the option "Alternative text is required" (Exponential 6.0.15 and later), because such a
  field refuses an empty alternative text. Its tooltip says why: "This field requires an alternative text, so it
  cannot be left empty." The model's remark that an image may be decorative is not shown for such a field. On a
  kernel without the option the button stays as before. New template fetch:
  `fetch( 'expai', 'alt_text_required', hash( 'attribute', $attribute ) )`; new method
  `expAiAltText::altTextRequired()`. See [alt-text.md](../alt-text.md).

The option "Alternative text is required" comes from LoveStack by Mugo Web, with thanks (LoveStack commit
a28863d9c0).
