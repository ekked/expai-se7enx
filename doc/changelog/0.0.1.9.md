# expai 0.0.1.9

Only the test suite changes; no class under `classes/`, no setting and no template.

## Fixed

- Fixed: The unit suite no longer depends on the language, region rule and operating system of the site it runs on
  (#6). On a German siteaccess with `[DataPolicy] DefaultRegions[]=eu;local` it compared translated messages and
  numbers (`1,2k`) with their English source, and the site's region rule kept content from the mock providers. The
  run now uses the eng-GB locale without translation and an empty `DefaultRegions`, in memory; the script runner
  uses `timeout` or `gtimeout` when one is installed, `/usr/bin/true` stands in where `/bin/true` is missing, and a
  language scope test picks a language other than the article's.
- Fixed: The unit suite runs without a database. Tests that reached the database without asking for it, and the
  guards of the vector tests after a skipped setUp(), ended in 92 errors; they are now skipped with the reason.
  With a usable database a connection error still fails the test.
