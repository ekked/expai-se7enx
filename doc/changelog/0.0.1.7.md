# expai 0.0.1.7

## Fixed

- Fixed: The command palette no longer writes "Undefined variable: 'Packer' in group 'eZJSCore'" to the error log
  when ezjscore.ini has no [eZJSCore] Packer setting. The setting is optional and is now read only when it is set;
  the pack level is unchanged.

## Updated

- Updated: "A step of this conversation is already running" is written to the debug log instead of as a warning. It
  is the expected answer to a second request while a step runs (the user is told and a queued turn tries again);
  other failures of a step are still logged as warnings.
