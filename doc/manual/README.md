# User manual: Exponential Intelligence and Vector

Each page answers one question about Exponential Intelligence in the administration: who can do it, the steps, what
can go wrong, and where to read more. The other pages of this documentation explain how it works and how it is set
up; these pages are for doing the task.

Exponential Intelligence writes drafts and suggestions with the AI model your site has set up. It works with your own
account and permissions, and it never publishes: you decide what happens with everything it writes.
