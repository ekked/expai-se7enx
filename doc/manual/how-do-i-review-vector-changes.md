# How do I review the changes Vector proposes?

In a staged thread, Vector does not write drafts at once. Every change waits in the **Changes** tab, where you accept,
reject or edit it per field and part. Only what you accept is written into drafts.

## Who can do this

The editor of the thread (`expai/write` and `expai/vector`).

## Steps

1. Open the thread in **Dashboard** > **EI: Vector** and open the **Changes** tab on the right.
2. Go through the proposals. For each part of a field, accept it, reject it, or edit the proposed text.
3. If the object changed since the proposal, resolve the conflict the tab shows before you accept.
4. Apply the accepted changes into drafts.
5. Open the drafts and send them for publishing as usual.
6. If something went wrong, use the checkpoints of the thread to go back to an earlier state.

## What can go wrong

- **A proposal conflicts.** Someone changed the object meanwhile. Rebase or reject the proposal.
- **You accepted too much.** The drafts are not published yet. Discard them, or restore a checkpoint.
